E1 - TV browser capabilities

Measure this browser with feature detection: WebGL2 and its limits, compressed texture extensions, Web Audio after the Run gesture, a binary WebSocket round trip, RTCPeerConnection presence, the requestAnimationFrame rate, Wake Lock, device memory, hardware concurrency, screen/DPR, and the user-agent string as a recorded value only.

The binary WebSocket check uses the existing /ws room flow on this dev server (it creates a throwaway room, hosts it, joins it, and sends one 26-byte Input frame). Nothing is uploaded; no analytics, cookies or PII. Copy the JSON result into docs/RESULTS.md by hand. Open this page through a URL printed by the dev server (LAN IP or localhost) so the WebSocket Origin allowlist matches.

KTX2 support is not inferred from ASTC: the exact compressed-extension list is recorded, and the Basis transcoder may still be needed.
