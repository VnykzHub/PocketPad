E4/E9/E15/G1 - LAN quality, clock fairness, lifecycle, join timing

Measures, from this browser to the dev server: E4 Ping/Pong RTT p50/p95, jitter and loss; E9 clock-offset estimation error between two sockets (the implied press-time error for two players pressing together); E15 hide/show timing and session-rejoin time; G1 page load to joined.

Nothing runs until you press Run. The first Run joins a room (a throwaway self-hosted room, or the external room below) and arms the lifecycle recorder. For E15, lock the screen or switch apps, come back, and press Run again. Room code, PIN, tokens and session are never written to the result. Open this page through a URL printed by the dev server (LAN IP or localhost) so the WebSocket Origin allowlist matches.
