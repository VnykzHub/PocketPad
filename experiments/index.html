lanpad device probes

Standalone D1 probes. Open a probe and press Run; nothing runs automatically. Copy the JSON result and record it by hand in docs/RESULTS.md. No analytics, uploads, cookies or PII.

Planned probes

  • E1 - TV browser capabilities

    WebGL2, compressed textures, Web Audio, binary WebSocket, WebRTC, rAF rate and Wake Lock on the TV browser.

  • E2 - Memory ceiling

    Allocates typed arrays and WebGL textures in steps until slowdown or failure; records the last stable step and the failure mode.

  • E3 - TV render benchmark

    Instanced quads, a static mesh and a texture atlas at 720p and 1080p; records p50/p95 frame time and draw calls.

  • E14 - Mixed content and LAN reachability

    Checks whether an HTTPS page can open ws:// or fetch http:// to a LAN address.

Self-test fixtures

  • WebGL2 failure display

    Intentionally throws a WebGL2 context error so the shared failure display can be checked without a real TV.
